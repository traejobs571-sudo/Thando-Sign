# Sign illustrations — sources & licenses

All images in this folder were downloaded from Wikimedia Commons
(https://commons.wikimedia.org) via `tool/download_signs.ps1`. Filenames are
the gesture-label slugs the app resolves at runtime.

- **Alphabet (`letter_*.png`)** — "Sign language A.svg" … "Sign language Z.svg",
  vectorized by Marnanel from the Gallaudet-TT font (released into the public
  domain). Category:ASL letters.
- **Number zero (`zero.png`)** — "Asl alphabet gallaudet (zero).svg", same
  Gallaudet-TT public-domain series.
- **Numbers 1–10 (`one.jpg` … `ten.jpg`)** — "LSQ 1.jpg" … "LSQ 10.jpg" by
  Danielle-Claude Bélanger (professional LSQ/ASL interpreter, Montréal);
  per the file descriptions these digit shapes are identical in LSQ and ASL.
- **Word signs (`*.jpg`)** — ASL posture photographs from the
  "ASL <handshape>@<location>" Commons dataset; each file's description
  documents the gloss ("posture of the ASL sign <GLOSS>").
- **Shopping set (`cart`, `cashier`, `discount`, `money`, `pay`, `sale`,
  `wallet` `.png`)** — flat-style sign illustrations bundled earlier.

Check each file's Commons page for the exact license terms (most are
CC BY-SA or public domain); keep attribution in distributed builds.

## Accuracy caveat

These images depict **American Sign Language** and are bundled as visual
proxies — Zimbabwe Sign Language has its own vocabulary (though the
fingerspelling alphabet is largely shared). Do not present these as
verified ZSL signs; treat them as placeholders until true ZSL assets are
sourced or captured.

Labels with no bundled image render the captured hand-landmark skeleton
when sample data exists, then a generic glyph — admins can attach or
generate per-gesture illustrations to replace them.
